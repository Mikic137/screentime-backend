ScreenTime Tracker

Escanea el código QR desde tu celular Android para descargar e instalar la aplicación directamente.

Descargar APK Directamente Ver Panel de Monitoreo

Pasos para instalar:

  1. Apunta la cámara de tu celular al código QR.
  2. Toca el enlace que aparece y confirma la descarga.
  3. Abre el archivo descargado y presiona Instalar (habilita orígenes desconocidos si el sistema lo solicita).
  4. Abre la app y concede el permiso para ejecutarse en segundo plano.
